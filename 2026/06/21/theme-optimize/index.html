hexo+next主题优化

引用图片

默认引用本地图片无法正常显示，需安装插件hexo-asset-img

将需要引用的图片放在_post文件夹下，文章名同名的文件夹里。如文章命为test.md，需在_post文件夹下建立同名文件夹test，将图片放入其中，md文件中引用图片方式为![](test/pic_name)

这里可以将hexo配置文件中的post_asset_folder设置为true，这样hexo new 命令新建文章时，会自动建立同名文件夹。

注意，有些教程让安装hexo-asset-image，这个插件有问题，不适配新版hexo，需要卸载这个插件。

这里遇到一个bug，直接将旧博客的文章拷贝过来时，文章中的图片并不能正常显示，每篇文章都得重新引用一次图片后才恢复正常

访客统计

最新next主题默认已配置不算子，busuanzi_count默认设置为ture即可。需要注意，浏览器广告拦截插件可能导致具体数据不显示，如Ghostery插件会拦截不算子网站的请求

评论系统

常见的有valine/waline，其中waline更加安全，但这两个评论系统依赖leanCloud后端服务，leanCloud将于2027年1月12日停止运营，故暂不考虑改该方案

gitalk/utterances评论系统。这两个均基于GitHub issues，基本原理为将每篇博客文章映射为 GitHub 仓库中的Issue，依托github进行评论存储。适合github生态，但有个缺点是评论需要登录github账号。

但gitalk会将client_id 与 client_secret 直接暴露在前端，存在安全隐患，utterances则相对安全，其权限仅作用于一个仓库。故这里简单介绍utterances评论系统的配置：

可参考utterances官网

  1. 新建一个仓库用于存储评论
  2. 点击此处安装utterances至新建的仓库
  3. 在_config.next.yml里进行配置

这里遇到一个问题，登录时弹出Example Domain页面，无法登录。原因是hexo配置文件中，url使用了默认的http://example.com，导致OAuth请求失败。应该修改为https://username.github.io
